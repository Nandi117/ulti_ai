# Neuro-Symbolic RL Game Engine

This project contains a fully functional 2D grid-based game engine in Python (Arcade/Pygame) and a Neuro-Symbolic Reinforcement Learning (RL) agent using PyTorch. 

## Project Structure
- `engine/`: The 2D grid-based game engine logic and environment simulations.
- `agent/`: The PyTorch-based neuro-symbolic multi-level architecture.
- `simulations/`: Scenarios, levels, and specific game rules to simulate.
- `tests/`: Unit and integration testing.
- `.agents/`: Custom Antigravity skills and rules for maintaining and building the project.

## Setup
1. Create a virtual environment: `python -m venv venv`
2. Activate the virtual environment: `venv\Scripts\activate` (Windows)
3. Install dependencies: `pip install -r requirements.txt`
